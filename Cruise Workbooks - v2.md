## 📖 About This Repository

Welcome to my personal "Cruise" workbooks — a curated collection of experiments, learning projects, and practical tools I've developed while exploring data science, algorithms, and productivity. The name reflects the journey of continuous learning and discovery.

## 🚀 Featured Projects & Workbooks

### 🎲 Monte Carlo Simulation
A deep dive into Monte Carlo methods for simulation and probabilistic modeling:
- Python notebooks with simulation code using NumPy, Pandas, and SciPy
- Real-world examples in finance, physics, and decision-making
- Interactive visualizations with Matplotlib, Seaborn, and Plotly
- Read the Article: Monte Carlo Methods Decoded

### 🧠 Game Theory
Exploring strategic decision-making with a focus on:
- Game theory fundamentals and Nash equilibria
- Intersection with Markov Chain Monte Carlo (MCS) methods
- Interactive Obsidian notes and strategy analyses
- Economics and behavioral science applications

### 🛒 Costco Price Auditor
A practical automation tool:
- Track and log price changes over time
- Identify trends for smarter purchasing decisions
- Python scripts and Claude-based code playbook

### 🥧 pi-mono
Computational approaches to calculate π:
- Monte Carlo estimation (dart-throwing method)
- Series expansions and numerical algorithms
- Comparison of accuracy and convergence rates

### 🤖 AI Learning Workbooks
Growing collection of AI/ML experiments:
- Hands-on model implementations using Scikit-learn and TensorFlow/PyTorch
- Prompt engineering examples
- Integration with various AI models and APIs

### 📊 FFT Workbook
Signal processing fundamentals:
- Frequency analysis and transformations using SciPy and NumPy
- Noise filtering techniques
- Practical applications in time-series data

### 🗓️ Cruise Workbook 2026
Travel planning and documentation:
- Detailed itinerary and port research
- Comprehensive packing lists
- Travel tips and logistics
- Personal planning tools and templates

### 🤗 Hugging Face Workbook
Complete hands-on guide for building AI apps with Hugging Face:
- **3 Progressive Projects**: Easy (Sentiment Analyzer) → Medium (Podcast Summarizer) → Hard (Custom Fine-tuned Chatbot)
- Built-in testing with `pytest` for each project
- Step-by-step setup and Google Colab support
- Covers pipelines, Gradio, audio processing (SoundFile, Librosa), and LoRA fine-tuning (PEFT, BitsAndBytes)
- Model hosting and sharing on Hugging Face Hub

## 🚀 Getting Started

### Quick Setup
Clone the repository:
```
git clone https://github.com/cwb4-dev/Cruise-Workbooks.git
cd Cruise-Workbooks
```

Each project has its own dependencies - check individual READMEs.

### What You'll Need
- **Python 3.8+** - Primary language for all workbooks
- **Jupyter Notebook/JupyterLab** - Interactive development and visualization
- **Obsidian** - Knowledge management for Game Theory notes
- **Common Python Libraries**: NumPy, Pandas, Matplotlib, Seaborn

### Project Quick Starts
For Monte Carlo Simulation:
```
cd Monte_Carlo_Simulation
pip install -r requirements.txt  # (if exists)
jupyter notebook
```

For Game Theory:
```
cd "Game Theory (deepseek-based)"
# Open Obsidian notes or run Python scripts
```

For Hugging Face projects:
```
cd Hugging_Face
# Follow the setup instructions in the workbook
```

For Cruise Workbook 2026:
```
cd Cruise-Workbook-2026
# Review itinerary and planning documents
```
